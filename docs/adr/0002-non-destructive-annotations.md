# 標記與原圖分開保存，輸出時才合成

照片是偵辦案件的證據，標記（圈選、箭頭、文字、編號、遮蔽）若直接畫進照片，原圖就消失，日後也無法修正。因此標記以獨立資料保存在照片旁、原圖永遠不變，畫面顯示與輸出 Word／PDF／ZIP 時才合成；ZIP 可另外附上原圖。這和「旋轉」直接改寫照片的做法刻意不同。

## Considered Options

- 直接畫進照片（與旋轉相同）：做法簡單，但原圖遺失、標記無法修改，不適合作為證據的照片。

## Consequences

- 旋轉照片時必須同步轉換標記座標；分割長截圖前要先提醒標記會被清除。
- 遮蔽只在輸出時套用，專案與原圖中仍保有未遮蔽的內容；要交給他人時應使用輸出的檔案，而不是專案檔或原圖。
