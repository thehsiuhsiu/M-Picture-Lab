# 改為兩欄版面，移除右側文件資料欄

2026-10-20 的改版採三欄（左專案、中照片、右文件資料），但工具列過度擁擠、功能難找。主要使用者是在派出所桌機上操作、不一定熟電腦的同事，因此改為兩欄：左側專案清單，右側照片編輯區；文件資料改成照片區上方可收合的卡片，版型、檢視與輸出集中在照片區頂端一列，列表檢視改成照片卡片，另保留可切換的小圖排序方便拖曳，照片大小滑桿移除。專案名稱與儲存狀態只在左欄清單標示，常見問題、深淺色、隱私權政策移到左欄底部，讓照片編輯區只留下工作相關的東西。

## Considered Options

- 保留三欄並重整工具：右欄長期佔掉照片區寬度，問題沒有解決。
- 步驟式流程（選版型→加照片→填說明→輸出）：未採用，使用者偏好所有工作在同一個編輯區完成。
