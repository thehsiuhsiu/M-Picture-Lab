# 刑事案件與交通事故版型共用一份版面規格，文字超過行數上限就不能列印或下載 PDF

Word、列印／PDF 檔案、版面預覽原本是三套各自寫的排版，邊界、字體大小、照片框高度逐漸不一致。改成由一份版面規格提供所有排版數字，以 Word 的設定為準；並為每個文字欄位訂行數上限（說明 2 行、交通事故說明 3 行、案由與單位 2 行、地址與日期 1 行），超過就擋下列印與 PDF 檔案，讓版面固定、不必處理「放不下要怎麼換頁」，各種輸出才能真正一致。Word 不擋，因為使用者可以在 Word 裡自行修改；Word 超過時照舊讓列長高、自然換頁。多格照片版型只有 PDF，不在此範圍；字型仍是 PDF 的選項，Word 固定標楷體。

## Considered Options

- PDF 由 Word 檔轉出：最一致，但瀏覽器做不到，需要伺服器並上傳照片。
- Word 改照列印的 HTML 排版產生：Word 會變得不好編輯。
- 放不下時讓文件自然接到下一頁：Word 做得到，但列印、PDF 與預覽難以同樣處理，三邊又會分歧。
