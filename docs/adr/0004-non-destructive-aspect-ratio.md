# 調整比例保留原圖，輸出時才拉伸

監視器照片常被壓成正方形，需要拉回原比例。比例一旦猜錯，直接改寫照片就會讓作為證據的原圖失真且回不去，因此調整比例比照標記（ADR-0002）：只把寬高比存成照片的設定，原圖不變，畫面顯示與輸出時才拉伸，隨時可改回原始比例。拉伸只放大不縮小，不讓細節流失。這和「旋轉」直接改寫照片的做法刻意不同。

## Considered Options

- 比照旋轉直接改寫照片：做法簡單，但按下「完成」後就回不到原圖。

## Consequences

- 旋轉時比例跟著轉（16:9 變 9:16）。
- 標記的位置跟著照片拉伸，但文字、編號、線條粗細不跟著變形。
- 長截圖分割會把比例套用進各分段，分割後無法再改回；分割前的提醒要說明這點。
