# PDF 檔案以文字繪製並內嵌開放字型，標楷體改用全字庫正楷體

原本 PDF 只能透過瀏覽器列印視窗另存。新增可直接下載的「PDF 檔案」時，選擇在瀏覽器中逐頁以文字與圖片重新繪製版面，並內嵌字型，讓文字可選取、檔案較小；「列印」照舊保留。網頁讀不到使用者電腦裡的標楷體，標楷體也不能隨網頁散布，因此選標楷體時，PDF 檔案改用政府開放授權的全字庫正楷體，字型缺字時以思源黑體補字。

## Considered Options

- 整頁轉成圖片再存成 PDF：看起來與列印完全相同、標楷體照用，但文字無法選取搜尋，檔案較大。
- 只保留列印另存 PDF：不需新程式，但每次都要經過列印視窗，手機上操作不便。

## Consequences

- PDF 檔案的版面是另一套繪製程式，版型或版面預覽改動時要同步修改，否則兩者會不一致。
- 選標楷體時，PDF 檔案與列印、Word 的字型會略有不同。
- 字型檔放在專案裡；全字庫正楷體依常用字、次常用字、罕用字拆成三個檔，用到才下載（常用字約 9 MB）。每次只把用到的字子集化後內嵌，PDF 檔案很小。
